Accordion / FAQ

Native <details> with elegant styling

What makes GarurSaili different?

The engine is native Rust, the vocabulary is hybrid (intent + primitive + utility), and the palette is poetic and original.

Does it work with my framework?

Yes — Garur emits plain CSS. Any framework that consumes a stylesheet works. There are guides for Next.js, Vite, and plain HTML.

Do I need a Rust toolchain?

No. Prebuilt binaries ship via npm for Linux, macOS, and Windows. Installation is a normal npm command.

Shorthands Compat aliases, mapped.

GarurSaili ships aliases for the conventions UnoCSS and WindiCSS popularized — jc-center, ai-center, sz-8, fx-1, and more. If you're migrating from either, your muscle memory still works. Every alias resolves at build time to exactly the CSS the long form would produce.

UnoCSS + WindiCSS compatible
·
Zero runtime cost
· Updated October 2026
Section 01 · Overview

What are shorthands?

A shorthand is a class name that expands to a longer, more explicit class name (or a combination of classes) at build time. jc-center expands to justify-content:center. sz-8 expands to width:2rem; height:2rem.

These shorthands are aliases, not replacements. You can use them alongside the native GarurSaili names — jc-center and justify-center both work, and both compile to the same thing. Choose whichever reads better to you.

GarurSaili native
justify-center items-center

Reads like English. The recommended default.

Compat alias
jc-center ai-center

Reads like UnoCSS. Same output.

expansion — identical output 
/* GarurSaili native */
.justify-center { justify-content: center; }
.items-center   { align-items: center; }

/* Compat alias */
.jc-center { justify-content: center; }
.ai-center { align-items: center; }

/* Both produce the same declaration, at the same layer. */

grid1 grid2 grid3 grid4 grid5 grid6 grid7 grid8 grid9 grid10 grid11 grid12
grid3 vs gc-3

Both produce the same result: display:grid; grid-template-columns:repeat(3, minmax(0, 1fr)). Use grid3 if you prefer the intent-style name, or gc-3 if you're coming from UnoCSS.

Section 15 · From UnoCSS

Migrating from UnoCSS

If you're moving from UnoCSS, most of your class names carry over unchanged. The remaining differences are in the config file and the CSS emission, not the class names themselves.

What stays the same

Category Compatible
Spacing utilitiesp-4 · m-2 · gap-3
Flex utilitiesjustify-center · items-center
Sizingw-full · max-w-xl · min-h-screen
Typographytext-lg · font-bold · leading-relaxed
Compat aliasesjc-center · ai-center · sz-8
Variantshover: · md: · dark:

What changes

The config file

Replace uno.config.ts with garur.config.js. The shape is similar — content globs, theme overrides, safelist — but the field names are different.

The build tool

Remove unocss from your bundler plugins. Replace with npx garur ssc ./src in a prebuild step.

Preset-specific classes

UnoCSS presets like preset-wind emit some class names GarurSaili doesn't have (icon utilities, attributify mode). Replace them with the native GarurSaili equivalents, or register a plugin that emits them.

uno.config.ts → garur.config.js 
// Before — uno.config.ts
import { defineConfig, presetUno } from 'unocss';

export default defineConfig({
  presets: [presetUno()],
  content: { filesystem: ['./src/**/*.{html,tsx}'] },
});

// After — garur.config.js
export default {
  content: ['./src/**/*.{html,tsx}'],
  output: './build/garur.css',
};

Migrating from WindiCSS

WindiCSS pioneered several of the shorthand conventions that GarurSaili adopted. Migration is even smoother than from UnoCSS, because WindiCSS's class names are almost identical to the ones GarurSaili ships as compat aliases.

WindiCSS GarurSaili Notes
jc-centerjc-centeridentical
ai-centerai-centeridentical
flex-colflex-colidentical
rounded-lgrounded-lgidentical
shadow-mdshadow-mdidentical
op-50op-50identical
gap-4gap-4identical

WindiCSS-specific features like @apply, @screen, and the variant group syntax all have GarurSaili equivalents. See the migration guide → for a full walkthrough.

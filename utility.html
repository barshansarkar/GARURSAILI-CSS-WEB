Home / Docs / Utility layer

The utility layer 5,000 atomic utilities.

The utility layer is the foundation of GarurSaili. Every class here maps to one (or a few) CSS properties. Combined with 50+ variants, 31 palette families, and 21 opacity steps, the engine can express tens of thousands of class names — all resolved at build time, with only the ones you use landing in the output.

Section 01 · Overview

What is a utility?

A utility is an atomic class. One class, one CSS declaration (or a small group of related declarations). p-4 sets padding: 1rem. bg-iris-500 sets background-color: #8657f7. flex sets display: flex.

Utilities are the bottom of GarurSaili's vocabulary stack. The intent layer (mid, apart-mid) and the primitive layer (card, btn) sit above it. Utilities win the cascade where they overlap, so writing card p-2 overrides the card's default padding.

Intent
mid

Semantic. Reads like a description.

Primitive
card

Component-level. Groups related properties.

Utility
p-4

Atomic. One property per class.

composition 
<!-- The full stack: intent + primitive + utility -->
<div class="mid card p-8 stack-4 hover:rise">
  <h2 class="headline text-iris-600 dark:text-iris-400">
    Hello
  </h2>
</div>

Read left to right: mid (intent — centered), card (primitive — full surface), p-8 (utility — overrides card padding), stack-4 (intent — vertical with gap), hover:rise (utility with variant — lift on hover).

Section 02 · Scales

Scales

Nearly every utility accepts a scale value. The same numeric token powers spacing, sizing, positioning, and gap — so p-4, m-4, gap-4, w-4, and top-4 all expand to the same 1rem.

The spacing scale

The scale is not linear. Small increments use 0.25rem steps, mid-range uses 0.5rem and 1rem, and large values jump in bigger leaps. This matches how designers think about spacing.

Named extended scale

Beyond the numeric tokens, GarurSaili includes an extended named scale for typography and section rhythm:

Inset & z-index

The inset family positions an element along one or more edges. All accept the spacing scale, negative values, fractions (1/2), and auto / full.
